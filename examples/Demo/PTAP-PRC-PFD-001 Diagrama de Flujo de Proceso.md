# `PTAP-PRC-PFD-001` · PFD del tren de tratamiento

Captación → desarenador → mezcla rápida (Parshall) → floculación hidráulica → sedimentación de alta tasa (placas) → filtración rápida (lecho dual) → desinfección (cloro gaseoso) → tanque de almacenamiento.
